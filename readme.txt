== Description ==

Unyson+ is a free, open-source **framework for WordPress** — a developer framework (options, settings, custom fields and an extension system) with a **built-in drag-and-drop page builder** and a library of modular extensions. Build pages visually with no code, style them with reusable presets, and add a theme builder, forms, WooCommerce, SEO, animations and more — all from one plugin, with no paid tier.

It is a community-maintained fork of the original Unyson framework (by ThemeFuse), continued and heavily modernized after the original was discontinued. Updates are delivered directly from GitHub releases (Plugin Update Checker), so no WordPress.org listing is required.

At its core is a powerful **options system** — developers define Theme Settings, meta boxes, custom fields and element options from one API. Built on that framework, the **drag-and-drop page builder** (responsive, 60+ elements, clean semantic output) is the flagship, alongside a theme builder, custom fields, post types, an animation engine, a site converter and 20+ modular extensions you enable only as needed.

**Who it's for**

* New site owners and beginners — build pages visually, no code required.
* Designers and freelancers — ready-made elements, presets and templates to ship fast.
* Developers — a mature options framework, custom fields, post types and hooks to build on.

**Highlights**

* **Page Builder.** Drag-and-drop builder with a Flexbox/Div-first layout model, a large library of elements, reusable Component Presets, Dynamic Content tags, and per-device responsive editing — with a clean, un-bloated frontend DOM and no Bootstrap dependency.
* **Theme Builder.** Build headers, footers and body templates with conditional assignment, using the same builder.
* **Options Framework.** Dozens of option types (color, typography, media, spacing, gradients, repeaters, and more) powering Theme Settings, element options and post meta boxes from one API.
* **Custom Fields & Post Types.** A custom field-group builder and a no-code custom-post-type creator.
* **Animation Engine.** A no-library motion system — scroll animations, parallax, text effects, Rive and 3D model elements, and more.
* **Site Converter.** Capture an existing page design by URL and turn it into a self-sufficient, editable WordPress theme and pages.
* **Extensions.** WooCommerce, Portfolio, Sidebars, Mega Menu, Forms, Breadcrumbs, Mailer, Blog, Snippets, Asset Optimizer, SEO, Template Library, Site Migration, and more — enable only what you need.

**Requirements**

* WordPress 5.8 or higher
* PHP 8.0 or higher

== Installation ==

The easiest way is to install the ready-to-use plugin ZIP from your WordPress dashboard:

1. Download the latest **unysonplus.zip** from the GitHub Releases page: https://github.com/UnysonPlus/UnysonPlus/releases/latest/download/unysonplus.zip
2. In WordPress, go to **Plugins → Add New → Upload Plugin**, choose the ZIP, and click **Install Now**.
3. Click **Activate**.
4. Open the new **Unyson+** menu, then **Unyson+ → Extensions** to switch on the features you want — the base install is lean and extensions download on demand.

Then edit any page and the Page Builder is ready to use. New to it? See https://docs.unysonplus.com/getting-started/build-your-first-page

**Developers** can instead clone the repository into `wp-content/plugins/` (folder named `unysonplus`) — but note the repository is core-only, so for a running site use the release ZIP above, not GitHub's "Download ZIP".

**Warning:** Unyson+ shares function names with the original Unyson plugin. If the original Unyson is installed, deactivate and delete it (or use a staging site / backup) before activating Unyson+ — running both at once will cause fatal errors.
