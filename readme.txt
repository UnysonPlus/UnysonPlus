A modern, community-maintained continuation of the Unyson framework — a page-builder-first website toolkit for WordPress.

== Description ==

Unyson+ is a community-maintained fork of the original Unyson framework (by ThemeFuse), continued after the original was discontinued. It keeps the framework alive and stable and grows it into a modern, page-builder-first website toolkit for WordPress.

It bundles an options framework, a visual page builder that outputs clean semantic HTML, a theme builder, custom post types and ACF-style custom fields, plus 20+ modular extensions — all free and GPL-licensed. Updates are delivered directly from GitHub releases (Plugin Update Checker), so no WordPress.org listing is required.

**Highlights**

* **Page Builder.** Drag-and-drop builder with a Flexbox/Div-first layout model, a large library of elements, reusable Component Presets, Dynamic Content tags, and per-device responsive editing — with a clean, un-bloated frontend DOM and no Bootstrap dependency.
* **Theme Builder.** Build headers, footers and body templates with conditional assignment, using the same builder.
* **Options Framework.** Dozens of option types (color, typography, media, spacing, gradients, repeaters, and more) powering Theme Settings, element options and post meta boxes from one API.
* **Custom Fields & Post Types.** An ACF-style field-group builder and a no-code custom-post-type creator.
* **Animation Engine.** A no-library motion system — scroll animations, parallax, text effects, Rive and 3D model elements, and more.
* **Site Converter.** Import an AI-generated design or capture a source site by URL and turn it into a self-sufficient WordPress theme.
* **Extensions.** WooCommerce, Portfolio, Sidebars, Mega Menu, Forms, Breadcrumbs, Mailer, Blog, Snippets, Asset Optimizer, SEO, Template Library, Site Migration, and more — enable only what you need.

**Requirements**

* WordPress 5.8 or higher
* PHP 8.0 or higher

== Installation ==

1. Download or clone the plugin into your WordPress `wp-content/plugins` directory (or install the release ZIP from the GitHub Releases page).
2. Activate **Unyson+** from **Plugins** in the WordPress dashboard.
3. Configure the framework from the **Unyson+** menu.

**Warning:** Unyson+ shares function names with the original Unyson plugin. If the original Unyson is installed, uninstall it (or use a staging site / backup) before activating Unyson+ — running both at once will cause fatal errors.
